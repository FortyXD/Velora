# Folis

Личный форк [end-4/dots-hyprland](https://github.com/end-4/dots-hyprland) с моими рабочими настройками Hyprland и Illogical Impulse на Quickshell. Основной конфиг Hyprland — Lua; старые Hyprland `.conf` удалены, а `hyprlock.conf` и `hypridle.conf` оставлены для соответствующих программ. Текущая оболочка: Kitty → tmux → zsh + Starship, файловый менеджер — Dolphin.

## Установка на Arch Linux

```bash
git clone --recurse-submodules https://github.com/FortyXD/Folis.git ~/Folis
cd ~/Folis
./install.sh --dry-run
./install.sh
```

`install.sh` устанавливает пакеты из `packages/arch.txt` через pacman и из `packages/aur.txt` через yay. Для полной установки нужен yay. Уже установленную систему можно связать без установки пакетов:

```bash
./install.sh --skip-packages
```

Скрипт перемещает существующие цели в `~/.local/state/folis/backups/<дата>-<pid>/`, создаёт символические ссылки из домашнего каталога на файлы форка, назначает Dolphin для каталогов и перезагружает Hyprland, если он запущен. `--no-reload` пропускает перезагрузку; `--skip-aur` пропускает AUR.

На другом компьютере проверьте экран `eDP-1` в `dots/.config/hypr/hyprland/general.lua` и путь к обоям в `dots/.config/illogical-impulse/config.json`. Они сняты с моего текущего устройства.

## Что добавлено поверх Illogical Impulse

### Конструктор панели

Любой виджет можно поставить в любую из пяти зон панели: слева, у центра слева, в центре, у центра справа, справа. Виджеты можно группировать в «пилюли» и скрывать на узких экранах. Есть свои кнопки, вывод команды, скорость сети, обновления и др. Стиль задаётся отдельно: высота, прозрачность, острова вместо сплошного фона, контурные пилюли, плавающая панель, тень текста, размытие под полупрозрачной панелью. Встроенная раскладка совпадает с оригинальной панелью.

- Настройки → «Панель» → «Расставить виджеты»: перетаскивание виджетов, их параметры, действия по клику и прокрутке для каждой зоны, готовые панели, экспорт и импорт.
- Правка прямо на панели: Shift + правый клик по панели, правый клик по пустому месту или `Super+Alt+J`. Esc — выход.

### Пресеты и образы

Настройки → «Пресеты». Образ — это обои, цвета, панель, док и виджеты рабочего стола, анимации окон. При применении можно выбрать, какие части взять; «Отменить» возвращает предыдущее состояние. «Сохранить текущее как мой вид» запоминает вашу систему как пресет по умолчанию, «Вернуть мой вид» восстанавливает её. Обои встроенных образов скачиваются при первом применении в `~/Pictures/Wallpapers/Presets/`.

Из лаунчера: `/preset ИМЯ`. Из терминала: `qs -c ii ipc call presets apply <id> ""` (список — `qs -c ii ipc call presets list`).

### Обои из интернета

Настройки → «Обои» → «Онлайн-источники». Поддерживаются Wallhaven, Unsplash, Pexels, Pixabay (у последних трёх нужен свой ключ API), Bing, NASA APOD, Wikimedia Commons, Reddit и Openverse. «Обои дня» каждый день ставят свежую картинку из Bing, NASA или Wikimedia и удаляют старые.

### Окно «Инструменты»

`Super+Shift+I`, кнопка панели «Инструменты» или `/toolbox` в лаунчере (`/toolbox ссылка` сразу открывает загрузку).

- Конвертер: изображения (PNG, JPG, WebP, AVIF, HEIC, ICO, PDF…), видео и звук (MP4, WebM, GIF, MP3, Opus, FLAC, обрезка, «уложить в N МБ»), документы (через pandoc и LibreOffice, если он установлен), PDF (страницы в картинки, склейка, сжатие), архивы.
- Загрузки: видео и музыка по ссылке через yt-dlp, с выбором качества, субтитрами и прокси.
- QR-коды: создание и чтение с экрана, из файла или буфера; ссылки открываются, к Wi‑Fi можно подключиться.
- Текст с картинок: tesseract для картинок, области экрана и PDF, в том числе PDF с поиском по тексту.
- Цвета: пипетка с историей (`Super+Shift+C` тоже её пополняет), HEX/RGB/HSL/OKLCH, палитра из картинки, «Сделать акцентом».

В Dolphin в контекстном меню появляются «Преобразовать в» (PNG, JPG, WebP, PDF, MP4, MP3… — без открытия окна, с уведомлением) и «Инструменты» (конвертер, распознать текст, сканировать QR). Меню ставит `./install.sh`.

## Разработка

Редактируйте файлы прямо в `dots/.config/`. Через ссылки изменения этих файлов доступны системе сразу; Hyprland и Quickshell при необходимости можно перезапустить:

```bash
hyprctl reload
qs kill -c ii
qs -d -c ii
```

Главные места для правок:

- `dots/.config/hypr/custom/*.lua` — личные настройки Hyprland. `custom/variables.lua` задаёт Kitty и Dolphin.
- `dots/.config/quickshell/ii/` — код и ресурсы Quickshell.
- `dots/.config/illogical-impulse/config.json` — пользовательские параметры оболочки.
- `dots/.config/kitty/`, `dots/.config/tmux/`, `home/.zshrc`, `home/.tmux.conf` — терминал и оболочка.
- `packages/` — списки пакетов.

Рабочий `dots/.config/illogical-impulse/config.json` хранится локально и исключён через `.gitignore`: изменения виджетов, их названия и даты не попадают в коммиты. При первой установке он создаётся из отслеживаемого `config.example.json`; существующий конфиг сохраняется. Для изменения общих настроек по умолчанию редактируйте шаблон без личных данных.

Другие настройки под связанными каталогами могут попадать в репозиторий. После правки `packages/` повторно запустите `./install.sh` для установки новых пакетов. Перед публикацией просматривайте `git diff`: настройки могут содержать личные пути или введённые позднее данные.

```bash
git status
git add dots home install.sh packages README.md
git commit -m "Customize Folis"
git push origin main
```

`upstream` указывает на оригинальный проект end-4. Обновления из него нужно сливать отдельно с проверкой конфликтов в Hyprland и Quickshell. Оригинальный `./setup` оставлен как часть форка; для установки этой версии используйте `./install.sh`, поскольку он поддерживает живые ссылки.
